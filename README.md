# 横動画ショート変換プログラム

長編の横型動画から、YouTube Shorts / TikTok / Instagram Reels 向けの縦動画を自動生成するローカルWebアプリです。

## 方針

- GitHubでコード管理
- Mac / Windowsの両方で動作
- UIはブラウザ
- 元動画は原則PC内で処理（GitHubへアップロードしない）
- FFmpegで動画変換
- 今後 Whisper 文字起こし + LLMによるショート候補評価を追加

## 現在のv0.7

- ブラウザUI起動
- 動画ドラッグ＆ドロップ
- FFmpeg / ffprobe環境確認
- 動画メタデータ取得
- ジョブID作成
- ローカルWhisperによる日本語文字起こし
- セグメント単位の開始・終了タイムコード保存
- バックグラウンド処理と進捗表示
- 30〜60秒を中心としたショート候補の自動ランキング
- 動画全体または秒数指定範囲だけを対象にした候補解析
- 10〜90秒の候補抽出、候補数の固定上限撤廃
- 上位30件を先に表示し、残りを30件ずつ追加表示
- 候補ごとのスコア・要約・選定理由・フック案表示
- ショート候補ごとの元映像プレビュー（開始・終了秒の編集に連動）
- OpenAI API設定時のAI評価と、未設定時のローカル評価
- YouTube URLからの動画読み込み
- 選択候補の1080x1920縦動画書き出し
- 複数候補から印象的な8〜15秒を選び、1本につなぐ再編集
- ブラウザ上で完成動画の再生・MP4保存
- Whisperタイムコードを使った大きい日本語字幕の焼き込み

- 候補ごとの動画上部固定タイトル（文章・サイズ・上下位置を編集可能）
- 字幕文章の編集、文字サイズ・表示位置（上／中央／下）の指定
- 字幕の上下位置をスライダーで10ピクセル単位に微調整
- 普段使うテロップ設定を標準値として起動（字幕100・上500、上部タイトル140、下部固定テロップ119・下から450）
- 候補ごとの開始・終了秒の調整（前後へ範囲を拡張可能）
- 字幕文章を空にした発話区間を映像・音声ごと削除し、前後を自動連結
- 候補ごとに9:16切り抜きの画角位置を左・中央・右から選択
- 横動画全体を中央に保持し、拡大・ぼかした同一映像を背景に敷く画角モード
- 完成動画のプレビュー・MP4保存・個別削除
- 固定タイトルと字幕テロップの手動改行
- 上部タイトルとは別の下部固定テロップ（文章・サイズ・位置を指定、空欄で非表示）
- 固定タイトルと字幕テロップ内の半角・全角スペースを保持
- 固定タイトルを最大200まで拡大
- 完成動画の最後だけに表示する締めテロップ（文章・サイズ・表示秒数）
- 完成動画ごとのYouTube概要欄・Instagram投稿文・TikTok投稿文・ハッシュタグ自動生成とコピー
- YouTube素材では元動画のタイトル・概要欄・チャンネル・本編URLを参考に概要欄を生成
- OpenAI API設定時は、選択区間の字幕全文と元YouTube概要欄をまとめて理解し、媒体別の投稿文を生成（失敗時はローカル生成へ自動切替）
- Ollamaと`qwen3:4b`が起動している場合は、無料のローカルAIを最優先で使用（字幕や概要欄はMac内で処理）
- Google OAuth認証後、完成動画をYouTube Shortsへバックグラウンド投稿（進捗・完了URL表示）
- YouTube 403を避ける互換MP4優先取得と、時間を空けた自動再試行

次の実装予定は、複数観点スコアとFamily / XRチャンネルプリセットです。

## 縦動画の生成

ショート候補にチェックを入れ、以下のどちらかを選びます。

- `選択候補をそれぞれ動画化`: 候補の開始〜終了をそのまま個別MP4にする
- `見どころをつないで1本にする`: 選択候補ごとの印象的な8〜15秒を抽出して連結する

出力は1080x1920 H.264/AAC MP4で、現在は元映像の中央を9:16にクロップします。

各候補の「動画上部の固定タイトル」と「字幕の文章を編集」から、書き出す内容を候補ごとに直せます。さらに書き出しボタンの上で字幕サイズと表示位置（上／中央／下）を指定できます。`大きい日本語字幕を入れる` をオンにすると、編集後の文章を白文字と黒縁で動画に焼き込みます。元動画に字幕が入っている場合はチェックを外してください。固定タイトルは字幕のオン／オフにかかわらず表示されます。

候補の開始・終了秒を変更すると、元の候補より前後へ範囲を広げたり短くしたりできます。「字幕の文章を編集」で文章を空欄にした場合、その発話時間は字幕だけでなく映像と音声もカットされ、残った区間が自動でつながります。

## ショート候補のAI評価（任意）

APIキーがない場合でも、文字起こしをPC内で評価して候補を表示します。より文脈を踏まえたAI評価を使う場合は、プロジェクト直下に `.env` を作成して以下を設定します。

```text
OPENAI_API_KEY=ここにAPIキー
OPENAI_MODEL=gpt-5.6-terra
```

OpenAI APIを使う場合、元動画は送信されず、文字起こしテキストとタイムコードのみが候補評価のために送信されます。API利用料金はOpenAI APIアカウントに課金されます。

## YouTubeから読み込む

ブラウザの「YouTubeの動画を使う」欄に自分の動画URLを貼り付けます。読み込み後はPCから選択した動画と同じように文字起こしできます。

- 公開または通常の限定公開URLに対応
- 1URLにつき1動画のみ読み込み
- ログイン必須の非公開動画は現時点では非対応

## YouTube Shortsへ投稿する

完成動画の「YouTubeへ投稿」は、最初にGoogle CloudのOAuth設定が必要です。

1. Google Cloud Consoleでプロジェクトを作成
2. `YouTube Data API v3`を有効化
3. OAuth同意画面を設定し、自分のGoogleアカウントをテストユーザーに追加
4. 「ウェブアプリケーション」のOAuthクライアントを作成
5. 承認済みリダイレクトURIに `http://127.0.0.1:8765/api/youtube/oauth/callback` を追加
6. `.env`にクライアントIDとシークレットを設定

```text
YOUTUBE_CLIENT_ID=Google CloudのクライアントID
YOUTUBE_CLIENT_SECRET=Google Cloudのクライアントシークレット
YOUTUBE_REDIRECT_URI=http://127.0.0.1:8765/api/youtube/oauth/callback
```

起動後に「YouTubeと接続」を押し、投稿先のYouTubeチャンネルを持つGoogleアカウントで許可します。認証トークンは `data/youtube_token.json` にローカル保存され、Gitには含まれません。

未審査のGoogle Cloud APIプロジェクトでは、API経由の投稿が非公開に制限される場合があります。最初は「非公開」で投稿し、YouTube Studioで確認してください。

## Whisperのセットアップ

Mac / Windowsとも起動スクリプトが `faster-whisper` を含む依存関係を自動インストールします。初回の文字起こし時にWhisperモデルがダウンロードされるため、インターネット接続と十分な空き容量を確保してください。2回目以降はキャッシュからローカル実行されます。

標準設定はCPU向けの `small` / `int8` です。速度または精度を変える場合は、`.env.example` を参考に起動前に環境変数を設定します。

```text
WHISPER_MODEL=tiny    # 高速・低精度
WHISPER_MODEL=small   # 標準
WHISPER_MODEL=medium  # 低速・高精度
WHISPER_DEVICE=cpu
WHISPER_COMPUTE_TYPE=int8
```

GPUを利用する場合は、GPU環境に合わせて `WHISPER_DEVICE=cuda` と `WHISPER_COMPUTE_TYPE=float16` を設定してください。GPU用CUDAライブラリの導入は `faster-whisper` 公式手順に従います。

## Windows

### 1. Python
Python 3.11 または 3.12 を推奨。

### 2. FFmpeg
winget が使える場合:

```powershell
winget install Gyan.FFmpeg
```

インストール後にPowerShellを開き直し、以下を確認:

```powershell
ffmpeg -version
ffprobe -version
```

### 3. 起動
`run_windows.bat` をダブルクリック。

ブラウザで以下が開きます:

`http://127.0.0.1:8765`

## macOS

Homebrewがある場合:

```bash
brew install ffmpeg python@3.12
```

その後 `run_mac.command` をダブルクリック、またはTerminalから:

```bash
./run_mac.command
```

## GitHubで複数PC運用

動画ファイルや生成物はGitに入れません。`.gitignore` で除外済みです。

基本フロー:

```bash
git pull
# 編集
git add .
git commit -m "説明"
git push
```

別PCでは `git pull` して最新コードを取得します。

Git操作が不慣れなPCでは GitHub Desktop 推奨です。

## 保存場所

- 入力動画: `data/uploads/`
- 出力動画: `data/outputs/`
- ジョブ情報: `data/jobs/`
- 文字起こし: `data/transcripts/`
- ショート候補: `data/candidates/`

これらはPCごとのローカルデータで、GitHubには送信されません。
